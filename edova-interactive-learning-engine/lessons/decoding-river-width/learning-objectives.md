# Learning Objectives — Decoding River Width

Objectives are organized by Bloom's Taxonomy level. Each objective maps to
the concept(s) it belongs to (see `concepts.md`).

## Remember

- **lo1** — State the definition of "line of sight" and "angle of sight"
  as used in indirect measurement.
  → Maps to: `c2`
- **lo2** — Recall the tangent ratio, `tan(θ) = opposite / adjacent`, for a
  right triangle.
  → Maps to: `c4`

## Understand

- **lo3** — Explain why a distance such as a river's width must be
  measured indirectly rather than directly.
  → Maps to: `c1`
- **lo4** — Describe how a real-world scenario (an observer, a baseline,
  and a distant landmark) is represented as a labelled right triangle.
  → Maps to: `c3`

## Apply

- **lo5** — Calculate an unknown side of a right triangle given one side
  (the baseline) and one angle, using the tangent ratio.
  → Maps to: `c4`, `c5`
- **lo6** — Substitute measured values (baseline = 40 m, angle = 30°) into
  `AC = AB × tan(B)` and compute the river width to one decimal place.
  → Maps to: `c5`

## Analyze

- **lo7** — Compare the angle predicted from a calculated width against a
  second, independently measured angle to determine whether the two
  triangles are consistent.
  → Maps to: `c6`
- **lo8** — Break down a new indirect-measurement scenario (e.g., the
  width of a canyon) into its baseline, right angle, and target components.
  → Maps to: `c3`, `c6`

## Evaluate

- **lo9** — Judge whether a calculated river width is reliable, given the
  size of the discrepancy between the predicted and measured verification
  angle.
  → Maps to: `c6`
- **lo10** — Justify why accurate angle measurement matters more than
  accurate baseline measurement when the baseline is short relative to the
  distance being found.
  → Maps to: `c2`, `c6`

## Create

- **lo11** — Design a complete measurement plan — where to place the
  baseline, which angle to measure, and how to verify the result — for a
  new, unseen scenario such as measuring the height of a cliff or the
  width of a canyon.
  → Maps to: `c3`, `c4`, `c6`
