# Chapter 1 -- Real Numbers

## Module 1: Part 2

## Number System Hierarchy

``` text
Real Numbers
├── Rational Numbers
│   └── Integers
│       └── Whole Numbers
│           └── Natural Numbers
└── Irrational Numbers
```

## Concept Explanation

-   Natural Numbers: 1,2,3,...
-   Whole Numbers: 0,1,2,...
-   Integers: ...,−2,−1,0,1,2,...
-   Rational Numbers: p/q, q≠0
-   Irrational Numbers: √2, √5, π
-   Real Numbers: Rational + Irrational

## Worked Examples

1.  7 → Natural, Whole, Integer, Rational, Real
2.  0 → Whole, Integer, Rational, Real
3.  −8 → Integer, Rational, Real
4.  3/4 → Rational, Real
5.  √4=2 → Natural, Whole, Integer, Rational, Real
6.  √7 → Irrational, Real
7.  π → Irrational, Real

## Classroom Teaching Script

Ask: 'Is every integer a rational number?' Discuss why.

## Activity

Sort number cards into the correct sets.

## Teaching Tips

-   Use colour coding.
-   Begin with familiar numbers.
-   Ask students to justify classifications.

## Practice Questions

1.  Classify 15, 0, −12, 8/9, √9, √11, π.
2.  Identify rational and irrational numbers.
3.  Draw a number line marking −3,0,2,5.

## Exit Ticket

-   Is every rational number an integer? Give an example.
-   Name one irrational number.
