# Competency-Based Examples

## Example 1: Choose the Criterion

In $\Delta ABC$ and $\Delta RQP$, $AB = 3.8$ cm, $BC = 6$ cm, $CA = 3$ cm, $RQ = 7.6$ cm, $QP = 12$ cm and $PR = 6$ cm. If $\angle A = 80°$ and $\angle B = 60°$, are the triangles similar? If yes, by which criterion? Also find $\angle P$.

**Solution:**

Check the ratios of corresponding sides:

$$\frac{AB}{RQ} = \frac{3.8}{7.6} = \frac{1}{2}$$

$$\frac{BC}{QP} = \frac{6}{12} = \frac{1}{2}$$

$$\frac{CA}{PR} = \frac{3}{6} = \frac{1}{2}$$

Since all three pairs of corresponding sides are proportional, by the SSS similarity criterion:

$$\Delta ABC \sim \Delta RQP$$

Therefore, $\angle C = \angle P$. Using the angle sum property:

$$\angle P = 180° - 80° - 60° = 40°$$

## Example 2: Error Analysis

A student claims that all equilateral triangles are congruent. Is the claim correct? Explain.

**Solution:**

The claim is incorrect. All equilateral triangles have the same shape (all angles $60°$ and sides in ratio $1:1:1$), so they are **similar**. However, they are congruent only when their side lengths are equal. Similar figures need not have the same size.

## Example 3: Formulate a Problem

Create a real-life problem that can be solved using the Basic Proportionality Theorem.

**Solution:**

Sample problem (based on Exercise 6.2):

"In $\Delta PQR$, $E$ and $F$ are points on sides $PQ$ and $PR$ respectively such that $PE = 4$ cm, $QE = 4.5$ cm, $PF = 8$ cm and $RF = 9$ cm. Show that $EF \parallel QR$."

Using Theorem 6.2:

$$\frac{PE}{QE} = \frac{4}{4.5} = \frac{8}{9}$$

$$\frac{PF}{RF} = \frac{8}{9}$$

Since $\dfrac{PE}{QE} = \dfrac{PF}{RF}$, by Theorem 6.2, $EF \parallel QR$.

## Example 4: Justify the Step

In a proof, a student writes: "$\Delta ABC \sim \Delta DEF$ because $\angle A = \angle D$ and $\angle B = \angle E$." Is this sufficient? Why?

**Solution:**

Yes, it is sufficient. If two angles of one triangle are equal to two angles of another triangle, then by the angle sum property the third angles are also equal. Therefore, by the AA similarity criterion, the triangles are similar. It is not necessary to check all three angles.
