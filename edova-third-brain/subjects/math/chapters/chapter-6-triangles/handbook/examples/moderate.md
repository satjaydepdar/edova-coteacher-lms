# Moderate Worked Examples

## Example 3: Proving a Triangle Is Isosceles

In $\Delta PQR$, $\dfrac{PS}{SQ} = \dfrac{PT}{TR}$ and $\angle PST = \angle PRQ$. Prove that $\Delta PQR$ is an isosceles triangle.

**Solution:**

Given:

$$\frac{PS}{SQ} = \frac{PT}{TR}$$

By the converse of the Basic Proportionality Theorem (Theorem 6.2):

$$ST \parallel QR$$

Therefore, $\angle PST = \angle PQR$ (corresponding angles). \quad ...(1)

Also given:

$$\angle PST = \angle PRQ \quad \text{...(2)}$$

From (1) and (2):

$$\angle PQR = \angle PRQ$$

Sides opposite equal angles are equal, so:

$$PQ = PR$$

Hence, $\Delta PQR$ is isosceles.

## Example 4: Parallel Lines and Vertically Opposite Angles

In the figure, $PQ \parallel RS$. Prove that $\Delta POQ \sim \Delta SOR$.

**Solution:**

Given: $PQ \parallel RS$.

Since $PQ \parallel RS$ and $PR$ is a transversal:

$$\angle P = \angle S \quad \text{(alternate angles)}$$

Since $PQ \parallel RS$ and $QS$ is a transversal:

$$\angle Q = \angle R \quad \text{(alternate angles)}$$

Also:

$$\angle POQ = \angle SOR \quad \text{(vertically opposite angles)}$$

Therefore, by the AAA similarity criterion:

$$\Delta POQ \sim \Delta SOR$$

## Example 5: Finding an Angle Using SSS Similarity

In $\Delta ABC$ and $\Delta PQR$,

$$AB = 3.8,\quad RQ = 7.6,\quad BC = 6,\quad QP = 12,\quad CA = 3,\quad PR = 6$$

Find $\angle P$.

**Solution:**

Calculate the ratios of corresponding sides:

$$\frac{AB}{RQ} = \frac{3.8}{7.6} = \frac{1}{2}$$

$$\frac{BC}{QP} = \frac{6}{12} = \frac{1}{2}$$

$$\frac{CA}{PR} = \frac{3}{6} = \frac{1}{2}$$

Thus:

$$\frac{AB}{RQ} = \frac{BC}{QP} = \frac{CA}{PR}$$

By the SSS similarity criterion:

$$\Delta ABC \sim \Delta RQP$$

Therefore, corresponding angles are equal:

$$\angle C = \angle P$$

Using the angle sum property in $\Delta ABC$:

$$\angle C = 180° - \angle A - \angle B = 180° - 80° - 60° = 40°$$

Hence:

$$\angle P = 40°$$
