**Q1.** In a classroom, 4 friends are seated at the points A, B, C and D as shown in Fig. 7.8. Champa asks Chameli, "Don't you think ABCD is a square?" Chameli disagrees. Using the distance formula, find which of them is correct.

**Q2.** If $Q(0, 1)$ is equidistant from $P(5, -3)$ and $R(x, 6)$, find the values of $x$. Also find the distances QR and PR.

**Q3.** To conduct Sports Day activities, in your rectangular shaped school ground ABCD, lines have been drawn with chalk powder at a distance of 1 m each. 100 flower pots have been placed at a distance of 1 m from each other along AD. **Q1.** *Note: Read the coordinates of A, B, C, D from Fig. 7.8 in the textbook.*

**Method:** Compute all four sides ($AB$, $BC$, $CD$, $DA$) and both diagonals ($AC$, $BD$) using the distance formula.

- If all four sides are equal **and** both diagonals are equal → ABCD is a **square** (Champa is correct).
- If all four sides are equal but diagonals are **not** equal → ABCD is a **rhombus**, not a square (Chameli is correct).
- If neither condition holds → ABCD is some other quadrilateral.

Apply this check to determine the answer.

**Q2.** $Q(0,1)$ is equidistant from $P(5,-3)$ and $R(x,6)$:

 $QP^2 = QR^2 \Rightarrow (0-5)^2 + (1+3)^2 = (0-x)^2 + (1-6)^2$ 
 $25 + 16 = x^2 + 25 \Rightarrow x^2 = 16 \Rightarrow x = \pm 4$ 
 $QR = \sqrt{(\pm 4 - 0)^2 + (6-1)^2} = \sqrt{16+25} = \sqrt{41}$ units

When $x = 4$: $PR = \sqrt{(4-5)^2+(6+3)^2} = \sqrt{1+81} = \sqrt{82}$ units

When $x = -4$: $PR = \sqrt{(-4-5)^2+(6+3)^2} = \sqrt{81+81} = \sqrt{162} = 9\sqrt{2}$ units

**Q3.** Green flag (Niharika): $x = 2$ (2nd line), $y = \dfrac{100}{4} = 25$ → $G(2,\; 25)$ 
Red flag (Preet): $x = 8$ (8th line), $y = \dfrac{100}{5} = 20$ → $R(8,\; 20)$ 
Distance between flags $= \sqrt{(8-2)^2 + (20-25)^2} = \sqrt{36+25} = \sqrt{61}$ m

Blue flag (midpoint of GR) $= \left(\dfrac{2+8}{2},\; \dfrac{25+20}{2}\right) = (5,\; 22.5)$ 
Rashmi should post the blue flag on the **5th line** at a height of **22.5 m**.

**Q4.** $AB = \sqrt{(1-4)^2+(7-2)^2} = \sqrt{9+25} = \sqrt{34}$ 
 $BC = \sqrt{(4+1)^2+(2+1)^2} = \sqrt{25+9} = \sqrt{34}$ 
 $CD = \sqrt{(-1+4)^2+(-1-4)^2} = \sqrt{9+25} = \sqrt{34}$ 
 $DA = \sqrt{(1+4)^2+(7-4)^2} = \sqrt{25+9} = \sqrt{34}$ 
 $AC = \sqrt{(1+1)^2+(7+1)^2} = \sqrt{4+64} = \sqrt{68}$ 
 $BD = \sqrt{(4+4)^2+(2-4)^2} = \sqrt{64+4} = \sqrt{68}$ 
All four sides $= \sqrt{34}$ (equal) and both diagonals $= \sqrt{68}$ (equal).

Therefore, ABCD is a **square**.

**Q5.** $(x-7)^2 + (y-1)^2 = (x-3)^2 + (y-5)^2$ 
 $x^2 - 14x + 49 + y^2 - 2y + 1 = x^2 - 6x + 9 + y^2 - 10y + 25$ 
 $-14x - 2y + 50 = -6x - 10y + 34$ 
 $-8x + 8y + 16 = 0$ 
 $\boxed{x - y = 2}$ 
**Q6.** Let point on y-axis be $P(0, y)$:

 $(6-0)^2 + (5-y)^2 = (-4-0)^2 + (3-y)^2$ 
 $36 + 25 - 10y + y^2 = 16 + 9 - 6y + y^2$ 
 $61 - 10y = 25 - 6y$ 
 $36 = 4y \Rightarrow y = 9$ 
The required point is $\mathbf{(0,\; 9)}$.

**Verification:** $AP = \sqrt{36+16} = \sqrt{52}$, $BP = \sqrt{16+36} = \sqrt{52}$. Confirmed equidistant.
