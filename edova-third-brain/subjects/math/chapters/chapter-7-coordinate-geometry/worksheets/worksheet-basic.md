### Distance Formula (Direct Substitution)

**Q1.** Find the distance between the following pairs of points:

(i) $(2, 3)$ and $(4, 1)$ 
(ii) $(-5, 7)$ and $(-1, 3)$ 
(iii) $(a, b)$ and $(-a, -b)$ 
**Q2.** Find the distance between the points $(0, 0)$ and $(36, 15)$. Can you now find the distance between the two towns A and B discussed in Section 7.2?

### Section Formula (Direct Application)

**Q3.** Find the coordinates of the point which divides the join of $(-1, 7)$ and $(4, -3)$ in the ratio $2 : 3$.

**Q4.** Find the coordinates of a point A, where AB is the diameter of a circle whose centre is $(2, -3)$ and B is $(1, 4)$.

**Q5.** Find the coordinates of the points which divide the line segment joining $A(-2, 2)$ and $B(2, 8)$ into four equal parts.

**Q6.** Find the coordinates of the point which divides the line segment joining the points $(4, -3)$ and $(8, 5)$ in the ratio $3 : 1$ internally.

<summary><strong>Answer Key</strong></summary>

**Q1.** (i) $AB = \sqrt{(4-2)^2 + (1-3)^2} = \sqrt{4+4} = \sqrt{8} = 2\sqrt{2}$ units

(ii) $AB = \sqrt{(-1+5)^2 + (3-7)^2} = \sqrt{16+16} = \sqrt{32} = 4\sqrt{2}$ units

(iii) $AB = \sqrt{(-a-a)^2 + (-b-b)^2} = \sqrt{4a^2 + 4b^2} = 2\sqrt{a^2 + b^2}$ units

**Q2.** $\text{AB} = \sqrt{36^2 + 15^2} = \sqrt{1296 + 225} = \sqrt{1521} = 39$ units. Yes, this is the distance between towns A and B.

**Q3.** $x = \dfrac{2(4) + 3(-1)}{2+3} = \dfrac{5}{5} = 1$, \quad $y = \dfrac{2(-3) + 3(7)}{2+3} = \dfrac{15}{5} = 3$ 
Point is $(1, 3)$.

**Q4.** Centre is the midpoint of AB: $\dfrac{x+1}{2} = 2 \Rightarrow x = 3$; $\dfrac{y+4}{2} = -3 \Rightarrow y = -10$ 
Point A is $(3, -10)$.

**Q5.** Let the points be $P_1, M, P_2$ dividing AB into four equal parts.

 $M$ (midpoint of AB) $= \left(\dfrac{-2+2}{2},\; \dfrac{2+8}{2}\right) = (0,\; 5)$ 
 $P_1$ (midpoint of AM) $= \left(\dfrac{-2+0}{2},\; \dfrac{2+5}{2}\right) = (-1,\; 3.5)$ 
 $P_2$ (midpoint of MB) $= \left(\dfrac{0+2}{2},\; \dfrac{5+8}{2}\right) = (1,\; 6.5)$ 
Points: $(-1,\; 3.5)$, $(0,\; 5)$, $(1,\; 6.5)$.

**Q6.** $x = \dfrac{3(8) + 1(4)}{3+1} = \dfrac{28}{4} = 7$, \quad $y = \dfrac{3(5) + 1(-3)}{3+1} = \dfrac{12}{4} = 3$ 
Point is $(7, 3)$.
