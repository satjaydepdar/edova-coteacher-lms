## Worksheet – Basic Level

### Q1. Find the distance between the following pairs of points:

(i) $(2, 3)$ and $(4, 1)$ 
 $$AB = \sqrt{(4-2)^2 + (1-3)^2} = \sqrt{4 + 4} = \sqrt{8} = 2\sqrt{2}\ \text{units}$$ 
(ii) $(-5, 7)$ and $(-1, 3)$ 
 $$AB = \sqrt{(-1+5)^2 + (3-7)^2} = \sqrt{16 + 16} = \sqrt{32} = 4\sqrt{2}\ \text{units}$$ 
(iii) $(a, b)$ and $(-a, -b)$ 
 $$AB = \sqrt{(-a-a)^2 + (-b-b)^2} = \sqrt{4a^2 + 4b^2} = 2\sqrt{a^2 + b^2}\ \text{units}$$ 
---

### Q2. Find the distance between $(0, 0)$ and $(36, 15)$.

 $$AB = \sqrt{36^2 + 15^2} = \sqrt{1296 + 225} = \sqrt{1521} = 39\ \text{units}$$ 
Yes, this is the distance between towns A and B discussed in Section 7.2.

---

### Q3. Find the point dividing $(-1, 7)$ and $(4, -3)$ in the ratio $2 : 3$.

 $$x = \frac{2(4) + 3(-1)}{2+3} = \frac{8-3}{5} = \frac{5}{5} = 1$$ 
 $$y = \frac{2(-3) + 3(7)}{2+3} = \frac{-6+21}{5} = \frac{15}{5} = 3$$ 
**Point:** $(1, 3)$ 
---

### Q4. AB is the diameter of a circle with centre $(2, -3)$ and $B(1, 4)$. Find A.

Centre = midpoint of AB:

 $$\frac{x + 1}{2} = 2 \implies x + 1 = 4 \implies x = 3$$ 
 $$\frac{y + 4}{2} = -3 \implies y + 4 = -6 \implies y = -10$$ 
**Point A:** $(3, -10)$ 
---

### Q5. Divide $A(-2, 2)$ and $B(2, 8)$ into four equal parts.

Midpoint M of AB: $\left(\dfrac{-2+2}{2},\; \dfrac{2+8}{2}\right) = (0,\; 5)$ 
Midpoint $P_1$ of AM: $\left(\dfrac{-2+0}{2},\; \dfrac{2+5}{2}\right) = (-1,\; 3.5)$ 
Midpoint $P_2$ of MB: $\left(\dfrac{0+2}{2},\; \dfrac{5+8}{2}\right) = (1,\; 6.5)$ 
**Three points:** $(-1,\; 3.5)$, $(0,\; 5)$, $(1,\; 6.5)$ 
---

### Q6. Point dividing $(4, -3)$ and $(8, 5)$ in ratio $3 : 1$.

 $$x = \frac{3(8) + 1(4)}{3+1} = \frac{28}{4} = 7$$ 
 $$y = \frac{3(5) + 1(-3)}{3+1} = \frac{12}{4} = 3$$ 
**Point:** $(7, 3)$

## Worksheet – Standard Level

### Q1. Are $(1, 5)$, $(2, 3)$ and $(-2, -11)$ collinear?

 $$AB = \sqrt{(2-1)^2 + (3-5)^2} = \sqrt{1+4} = \sqrt{5}$$ 
 $$BC = \sqrt{(-2-2)^2 + (-11-3)^2} = \sqrt{16+196} = \sqrt{212}$$ 
 $$AC = \sqrt{(-2-1)^2 + (-11-5)^2} = \sqrt{9+256} = \sqrt{265}$$ 
 $AB + BC = \sqrt{5} + \sqrt{212} \neq \sqrt{265} = AC$ 
**Answer:** Not collinear.

### Q2. Are $(5, -2)$, $(6, 4)$ and $(7, -2)$ vertices of an isosceles triangle?

 $$AB = \sqrt{1+36} = \sqrt{37}, \quad BC = \sqrt{1+36} = \sqrt{37}, \quad AC = \sqrt{4+0} = 2$$ 
 $AB = BC$ 
**Answer:** Yes, isosceles triangle (with $AB = BC$).

### Q3. Name the quadrilateral:

 $AB = BC = CD = DA = 2\sqrt{2}$; $AC = BD = 4$ 
All sides equal, both diagonals equal.

**Answer:** Square

**(ii)** $(-3, 5)$, $(3, 1)$, $(0, 3)$, $(-1, -4)$ 
 $AB = \sqrt{52}$, $BC = \sqrt{13}$, $CD = \sqrt{50}$, $DA = \sqrt{85}$ 
All sides different lengths.

**Answer:** No specific quadrilateral (a general quadrilateral)

**(iii)** $(4, 5)$, $(7, 6)$, $(4, 3)$, $(1, 2)$ 
 $AB = CD = \sqrt{10}$; $BC = DA = 3\sqrt{2}$ (opposite sides equal)

 $AC = 2$, $BD = \sqrt{52}$ (diagonals not equal)

**Answer:** Parallelogram (not a rectangle)

### Q4. Point on x-axis equidistant from $(2, -5)$ and $(-2, 9)$.

Let point be $(x, 0)$:

 $$(x-2)^2 + 25 = (x+2)^2 + 81$$ 
 $$x^2 - 4x + 4 + 25 = x^2 + 4x + 4 + 81$$ 
 $$-8x = 56 \implies x = -7$$ 
**Point:** $(-7,\; 0)$ 
---

### Q5. Values of $y$ for which distance $P(2, -3)$ to $Q(10, y)$ is $10$.

 $$\sqrt{(10-2)^2 + (y+3)^2} = 10$$ 
 $$64 + (y+3)^2 = 100$$ 
 $$(y+3)^2 = 36 \implies y+3 = \pm 6$$ 
 $$y = 3 \quad \text{or} \quad y = -9$$ 
---

### Q6. Relation between $x$ and $y$ equidistant from $(3, 6)$ and $(-3, 4)$.

 $$(x-3)^2 + (y-6)^2 = (x+3)^2 + (y-4)^2$$ 
 $$x^2 - 6x + 9 + y^2 - 12y + 36 = x^2 + 6x + 9 + y^2 - 8y + 16$$ 
 $$-6x - 12y + 45 = 6x - 8y + 25$$ 
 $$-12x - 4y + 20 = 0$$ 
 $$\boxed{3x + y = 5}$$ 
---

### Q7. Points of trisection of $(4, -1)$ and $(-2, -3)$.

 $P$ (divides in $1:2$):

 $$P = \left(\frac{1(-2)+2(4)}{3},\; \frac{1(-3)+2(-1)}{3}\right) = \left(\frac{6}{3},\; \frac{-5}{3}\right) = \left(2,\; -\frac{5}{3}\right)$$ 
 $Q$ (divides in $2:1$):

 $$Q = \left(\frac{2(-2)+1(4)}{3},\; \frac{2(-3)+1(-1)}{3}\right) = \left(\frac{0}{3},\; \frac{-7}{3}\right) = \left(0,\; -\frac{7}{3}\right)$$ 
**Points:** $\left(2,\; -\dfrac{5}{3}\right)$ and $\left(0,\; -\dfrac{7}{3}\right)$ 
---

### Q8. Ratio in which $(-1, 6)$ divides $(-3, 10)$ and $(6, -8)$.

Let ratio be $k:1$:

 $$-1 = \frac{6k + (-3)}{k+1} \implies -k - 1 = 6k - 3 \implies 7k = 2 \implies k = \frac{2}{7}$$ 
*Verification with y-coordinate:*

 $$6 = \frac{-8k + 10}{k+1} \implies 6k + 6 = -8k + 10 \implies 14k = 4 \implies k = \frac{2}{7} \checkmark$$ 
**Ratio:** $2:7$ 
---

### Q9. Ratio in which x-axis divides $A(1, -5)$ and $B(-4, 5)$.

On x-axis, $y = 0$. Let ratio be $k:1$:

 $$0 = \frac{5k + (-5)}{k+1} \implies 5k - 5 = 0 \implies k = 1$$ 
**Ratio:** $1:1$ 
Point of division: $\left(\dfrac{1(-4)+1(1)}{2},\; 0\right) = \left(-\dfrac{3}{2},\; 0\right)$ 
---

### Q10. Find $x$ and $y$ if $(1, 2)$, $(4, y)$, $(x, 6)$, $(3, 5)$ form a parallelogram.

Midpoint of AC = Midpoint of BD:

 $$\frac{1+x}{2} = \frac{4+3}{2} \implies 1+x = 7 \implies x = 6$$ 
 $$\frac{2+6}{2} = \frac{y+5}{2} \implies 8 = y + 5 \implies y = 3$$ 
**Answer:** $x = 6$, $y = 3$ 
---

### Q11. $AP = \dfrac{3}{7}AB$, $A(-2, -2)$, $B(2, -4)$. Find P on AB.

 $AP = \frac{3}{7}AB$ means P divides AB in ratio $3:4$.

 $$P = \left(\frac{3(2)+4(-2)}{7},\; \frac{3(-4)+4(-2)}{7}\right) = \left(\frac{6-8}{7},\; \frac{-12-8}{7}\right) = \left(-\frac{2}{7},\; -\frac{20}{7}\right)$$ 
---

### Q12. Area of rhombus with vertices $(3, 0)$, $(4, 5)$, $(-1, 4)$, $(-2, -1)$.

Diagonal $AC = \sqrt{(-1-3)^2 + (4-0)^2} = \sqrt{16+16} = \sqrt{32} = 4\sqrt{2}$ 
Diagonal $BD = \sqrt{(-2-4)^2 + (-1-5)^2} = \sqrt{36+36} = \sqrt{72} = 6\sqrt{2}$ 
 $$\text{Area} = \frac{1}{2} \times 4\sqrt{2} \times 6\sqrt{2} = \frac{1}{2} \times 48 = 24\ \text{sq. units}$$

### Q1. Classroom seating — Is ABCD a square? (Fig. 7.8)

*Note: Read the coordinates of A, B, C, D from Fig. 7.8 in the textbook.*

**Method:**

1. Calculate all four sides: $AB$, $BC$, $CD$, $DA$ using the distance formula.
2. Calculate both diagonals: $AC$ and $BD$.
3. **Check:**
   - If all four sides equal **and** both diagonals equal → **Square** (Champa is correct)
   - If all four sides equal but diagonals are **not** equal → **Rhombus**, not a square (Chameli is correct)
   - If neither → Some other quadrilateral

### Q2. $Q(0, 1)$ equidistant from $P(5, -3)$ and $R(x, 6)$. Find $x$, QR, and PR.

 $$QP^2 = QR^2 \implies (0-5)^2 + (1+3)^2 = (0-x)^2 + (1-6)^2$$ 
 $$25 + 16 = x^2 + 25 \implies x^2 = 16 \implies x = \pm 4$$ 
 $$QR = \sqrt{(\pm 4)^2 + (6-1)^2} = \sqrt{16+25} = \sqrt{41}\ \text{units}$$ 
**When $x = 4$:** $PR = \sqrt{(4-5)^2 + (6+3)^2} = \sqrt{1+81} = \sqrt{82}$ units

**When $x = -4$:** $PR = \sqrt{(-4-5)^2 + (6+3)^2} = \sqrt{81+81} = 9\sqrt{2}$ units

### Q4. Show that $(1, 7)$, $(4, 2)$, $(-1, -1)$, $(-4, 4)$ are vertices of a square.

 $$AB = \sqrt{(1-4)^2+(7-2)^2} = \sqrt{9+25} = \sqrt{34}$$ 
 $$BC = \sqrt{(4+1)^2+(2+1)^2} = \sqrt{25+9} = \sqrt{34}$$ 
 $$CD = \sqrt{(-1+4)^2+(-1-4)^2} = \sqrt{9+25} = \sqrt{34}$$ 
 $$DA = \sqrt{(1+4)^2+(7-4)^2} = \sqrt{25+9} = \sqrt{34}$$ 
 $$AC = \sqrt{(1+1)^2+(7+1)^2} = \sqrt{4+64} = \sqrt{68}$$ 
 $$BD = \sqrt{(4+4)^2+(2-4)^2} = \sqrt{64+4} = \sqrt{68}$$ 
All four sides $= \sqrt{34}$ (equal) and both diagonals $= \sqrt{68}$ (equal).

Therefore, ABCD is a **square**.

*Alternative:* $AD^2 + DC^2 = 34 + 34 = 68 = AC^2$, so $\angle D = 90°$. A quadrilateral with all sides equal and one angle $90°$ is a square.

### Q5. Relation between $x$ and $y$ equidistant from $(7, 1)$ and $(3, 5)$.

 $$(x-7)^2 + (y-1)^2 = (x-3)^2 + (y-5)^2$$ 
 $$x^2 - 14x + 49 + y^2 - 2y + 1 = x^2 - 6x + 9 + y^2 - 10y + 25$$ 
 $$-14x - 2y + 50 = -6x - 10y + 34$$ 
 $$-8x + 8y + 16 = 0$$ 
 $$\boxed{x - y = 2}$$ 
This is the equation of the perpendicular bisector of the segment joining $(7, 1)$ and $(3, 5)$.

### Q6. Point on y-axis equidistant from $A(6, 5)$ and $B(-4, 3)$.

Let point be $P(0, y)$:

 $$(6-0)^2 + (5-y)^2 = (-4-0)^2 + (3-y)^2$$ 
 $$36 + 25 - 10y + y^2 = 16 + 9 - 6y + y^2$$ 
 $$61 - 10y = 25 - 6y$$ 
 $$36 = 4y \implies y = 9$$ 
**Point:** $(0,\; 9)$ 
*Verification:* $AP = \sqrt{36+16} = \sqrt{52}$; $BP = \sqrt{16+36} = \sqrt{52}$ ✓
