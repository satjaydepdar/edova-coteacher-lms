## Example 1 — Prove a quadrilateral is a square

Show that (1, 7), (4, 2), (−1, −1) and (−4, 4) are vertices of a square.

**Solution:**
AB = √[(1−4)² + (7−2)²] = √[9 + 25] = √34
BC = √[(4+1)² + (2+1)²] = √[25 + 9] = √34
CD = √[(−1+4)² + (−1−4)²] = √[9 + 25] = √34
DA = √[(1+4)² + (7−4)²] = √[25 + 9] = √34
AC = √[(1+1)² + (7+1)²] = √[4 + 64] = √68
BD = √[(4+4)² + (2−4)²] = √[64 + 4] = √68

All 4 sides equal (√34) and both diagonals equal (√68).
Therefore, ABCD is a square.

**Alternative:** AD² + DC² = 34 + 34 = 68 = AC². By converse of Pythagoras, ∠D = 90°. Quadrilateral with all sides equal and one angle 90° is a square.

## Example 2 — Finding relation for equidistant point

Find a relation between x and y such that (x, y) is equidistant from (3, 6) and (−3, 4).

**Solution:**
AP² = BP²
(x − 3)² + (y − 6)² = (x + 3)² + (y − 4)²
x² − 6x + 9 + y² − 12y + 36 = x² + 6x + 9 + y² − 8y + 16
−6x − 12y + 45 = 6x − 8y + 25
−12x + 4y = −20
3x − y = 5

## Example 3 — Point on x-axis equidistant from two points

Find the point on the x-axis equidistant from (2, −5) and (−2, 9).

**Solution:**
Let P(a, 0) be the point.
AP² = BP²
(a − 2)² + (0 + 5)² = (a + 2)² + (0 − 9)²
a² − 4a + 4 + 25 = a² + 4a + 4 + 81
−4a + 29 = 4a + 85
−8a = 56
a = −7
P = (−7, 0)

## Example 4 — Ratio of division by y-axis

Find the ratio in which the y-axis divides the segment joining (5, −6) and (−1, −4). Also find the point.

**Solution:**
Let ratio be k : 1. Point of division:
x = (k×(−1) + 1×5)/(k + 1)
On y-axis, x = 0:
(−k + 5)/(k + 1) = 0
−k + 5 = 0 → k = 5
Ratio = 5 : 1

Point: y = (5×(−4) + 1×(−6))/(5 + 1) = (−20 − 6)/6 = −26/6 = −13/3
Point = (0, −13/3)
