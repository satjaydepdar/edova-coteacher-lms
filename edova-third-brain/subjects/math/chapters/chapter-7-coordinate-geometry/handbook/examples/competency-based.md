## Example 1 — Justify the figure type

The points A(0, −1), B(2, 1), C(0, 3) and D(−2, 1) form a quadrilateral. Without calculating all distances, determine what type of quadrilateral it is. Then verify.

**Approach:** Plot the points mentally or on paper. A is at the bottom, C at the top, B and D on the sides. The pattern suggests a rhombus or square. Calculate to verify.

**Solution:**
AB = √[4 + 4] = √8
BC = √[4 + 4] = √8
CD = √[4 + 4] = √8
DA = √[4 + 4] = √8
AC = √[0 + 16] = 4
BD = √[16 + 0] = 4
All sides equal, diagonals equal → Square.

## Example 2 — Find unknown coordinate

If Q(0, 1) is equidistant from P(5, −3) and R(x, 6), find x. Also find QR and PR.

**Solution:**
QP² = QR²
(5−0)² + (−3−1)² = (x−0)² + (6−1)²
25 + 16 = x² + 25
x² = 16
x = ±4

When x = 4: QR = √[16 + 25] = √41, PR = √[1 + 81] = √82
When x = −4: QR = √[16 + 25] = √41, PR = √[81 + 81] = 9√2

## Example 3 — Error detection

A student claims that (1, 1), (−1, −1), (−1, 1) and (1, −1) form a square because all four sides equal √8. Is this correct? If not, explain.

**Solution:**
All four sides = √8. But diagonals:
AC = √[4 + 4] = √8
BD = √[4 + 4] = √8
Both diagonals are also √8. Since in a square, diagonal = side×√2, we should get diagonal = √8 × √2 = 4. But we get √8.
This is actually a square rotated 45° — wait, let me recalculate.
AC = √[(−1−1)² + (−1−1)²] = √[4 + 4] = √8. That's wrong for a square.
Actually: the points form a square. Side = √8, diagonal should be √8 × √2 = 4. But AC = √[(−2)² + (−2)²] = √8. This is NOT 4. So it's NOT a square — it's a rhombus.

## Example 4 — Design a problem

"Create a set of four points that form a rectangle but NOT a square. Prove your answer."

**Sample answer:** (0, 0), (4, 0), (4, 2), (0, 2).
Sides: 4, 2, 4, 2. Diagonals: √20, √20.
Opposite sides equal + equal diagonals = Rectangle. Sides not all equal, so not a square.
