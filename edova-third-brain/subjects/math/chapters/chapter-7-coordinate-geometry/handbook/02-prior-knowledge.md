## From Class IX — Coordinate Geometry

- Plotting points in the Cartesian plane
- Identifying the quadrant of a given point
- Understanding x-coordinate (abscissa) and y-coordinate (ordinate)
- Points on the x-axis: (x, 0); points on the y-axis: (0, y)
- Origin: (0, 0)
- Graphing linear equations in two variables (ax + by + c = 0) as straight lines
- Identifying the graph of y = ax² + bx + c as a parabola

## From Class IX — Number System

- Square roots and simplification of surds (e.g., √50 = 5√2)
- Operations on real numbers

## From Class IX — Geometry

- Pythagoras' theorem: In a right triangle, hypotenuse² = base² + height²
- Converse of Pythagoras' theorem: If a² + b² = c², the triangle is right-angled
- Properties of triangles, quadrilaterals (square, rectangle, rhombus, parallelogram)
- Similarity of triangles — AA similarity criterion
- Basic properties of parallelograms (diagonals bisect each other)

## From Class IX — Algebra

- Solving linear equations in one variable
- Substituting values into algebraic expressions
- Expanding and simplifying expressions like (x – a)² = x² – 2ax + a²
