## Geometric verification — decision tree

Given 4 points → Calculate all 4 sides + 2 diagonals:
- All 4 sides equal + both diagonals equal → SQUARE
- All 4 sides equal + diagonals NOT equal → RHOMBUS
- Opposite sides equal + both diagonals equal → RECTANGLE
- Diagonals bisect each other → PARALLELOGRAM

Given 3 points → Calculate all 3 sides:
- All 3 equal → EQUILATERAL
- 2 equal → ISOSCELES
- a² + b² = c² → RIGHT TRIANGLE
- None of the above → SCALENE

## Collinearity

Find AB, BC, AC. If AB + BC = AC (where AC is the largest), points are collinear.

## Equidistant point problems

**Type 1:** Set AP² = BP², expand, simplify to get a linear relation between x and y (perpendicular bisector of AB).

**Type 2:** Point on an axis → substitute (a, 0) or (0, b) and solve.
