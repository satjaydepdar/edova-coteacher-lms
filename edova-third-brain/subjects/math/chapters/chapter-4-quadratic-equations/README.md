# Chapter 4 - Quadratic Equations

## Overview
This directory contains curated resources for teaching and learning **Quadratic Equations** in CBSE Class 10 Mathematics.

- `handbook/` - Teacher handbook with notes, strategies, and reflections
- `lesson-plans/` - Ready-to-use lesson plans
- `worksheets/` - Practice worksheets (basic, standard, HOTS, case study, lesson-aligned)
- `assessments/` - Diagnostic, formative, summative assessments and rubrics
- `question-bank/` - Categorized question bank
- `activities/` - Classroom, experiential, art, and ICT integration activities
- `assets/` - Diagrams, illustrations, graphs, and classroom images
- `glossary.md` - Key terms and definitions
- `references.md` - NCERT, CBSE, and additional resource references
