# Challenge Problems

**Q1.** If $\alpha$ and $\beta$ are roots of $x^2 - 5x + 6 = 0$, find $\alpha^2 + \beta^2$.

**Q2.** Form the quadratic equation whose roots are $\dfrac{\sqrt{6}}{3}$ and $\dfrac{\sqrt{6}}{3}$ (repeated root from NCERT Example 5).

**Q3.** Find all real values of $k$ for which the equation $x^2 - 2kx + k^2 - 1 = 0$ has real and distinct roots.

**Q4.** If $x = 1$ is a common root of $x^2 + ax + b = 0$ and $x^2 + cx + d = 0$, find a relation between $a$, $b$, $c$, $d$.

**Q5.** Solve: $\dfrac{1}{x - 2} + \dfrac{2}{x - 1} = \dfrac{6}{x}$, where $x \neq 0, 1, 2$.

**Q6.** A cottage industry produces pottery articles. The cost of production of each article is ₹3 more than twice the number of articles produced. If total cost is ₹90, find the number of articles and cost per article.

---

## Answers

**A1.** $\alpha + \beta = 5$, $\alpha\beta = 6$.

$$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = 25 - 12 = 13$$

**A2.** Sum = $\dfrac{2\sqrt{6}}{3}$, Product = $\dfrac{6}{9} = \dfrac{2}{3}$.

Equation: $x^2 - \dfrac{2\sqrt{6}}{3}x + \dfrac{2}{3} = 0$

Multiply by 3: $3x^2 - 2\sqrt{6}x + 2 = 0$.

**A3.** $D = 4k^2 - 4(k^2 - 1) = 4 > 0$ for all real $k$.

So the equation always has real and distinct roots for all real $k$.

**A4.** Substituting $x = 1$:

$1 + a + b = 0$ and $1 + c + d = 0$

So $a + b = c + d$.

**A5.** Multiply by $x(x - 1)(x - 2)$:

$x(x - 1) + 2x(x - 2) = 6(x - 1)(x - 2)$

$x^2 - x + 2x^2 - 4x = 6x^2 - 18x + 12$

$3x^2 - 5x = 6x^2 - 18x + 12$
$3x^2 - 13x + 12 = 0$
$(3x - 4)(x - 3) = 0$

$x = \dfrac{4}{3}$ or $x = 3$.

**A6.** Let number of articles = $x$.

Cost per article = $(2x + 3)$ rupees.

$x(2x + 3) = 90$
$2x^2 + 3x - 90 = 0$
$(2x + 15)(x - 6) = 0$

$x = 6$.

Number of articles = 6, Cost per article = ₹15.
