# Moderate Worked Examples

## Example 1: Factorisation with irrational coefficients

Find the roots of $3x^2 - 2\sqrt{6}x + 2 = 0$.

**Solution:**

Split $-2\sqrt{6}x$ as $-\sqrt{6}x - \sqrt{6}x$.

$$3x^2 - \sqrt{6}x - \sqrt{6}x + 2 = 0$$
$$= \sqrt{3}x(\sqrt{3}x - \sqrt{2}) - \sqrt{2}(\sqrt{3}x - \sqrt{2})$$
$$= (\sqrt{3}x - \sqrt{2})(\sqrt{3}x - \sqrt{2})$$

So, $(\sqrt{3}x - \sqrt{2})^2 = 0$

Therefore, $x = \dfrac{\sqrt{2}}{\sqrt{3}} = \dfrac{\sqrt{6}}{3}$.

This root is repeated twice.

## Example 2: Word problem — consecutive integers

Find two consecutive positive integers, sum of whose squares is 365.

**Solution:**

Let the integers be $x$ and $x + 1$.

$$x^2 + (x + 1)^2 = 365$$
$$x^2 + x^2 + 2x + 1 = 365$$
$$2x^2 + 2x - 364 = 0$$
$$x^2 + x - 182 = 0$$

Factorise:

$$(x + 14)(x - 13) = 0$$

$x = 13$ (since $x$ must be positive).

The integers are 13 and 14.

## Example 3: Equal roots condition

Find $k$ if the equation $2x^2 + kx + 3 = 0$ has equal roots.

**Solution:**

For equal roots, $b^2 - 4ac = 0$:

$$k^2 - 4(2)(3) = 0$$
$$k^2 - 24 = 0$$
$$k = \pm 2\sqrt{6}$$

## Example 4: Discriminant

Find the discriminant of $3x^2 - 2x + \dfrac{1}{3} = 0$ and hence find the nature of its roots.

**Solution:**

$a = 3$, $b = -2$, $c = \dfrac{1}{3}$

$$b^2 - 4ac = (-2)^2 - 4(3)\left(\dfrac{1}{3}\right) = 4 - 4 = 0$$

Since the discriminant is 0, the equation has two equal real roots.

The root is $x = \dfrac{-b}{2a} = \dfrac{2}{6} = \dfrac{1}{3}$.
