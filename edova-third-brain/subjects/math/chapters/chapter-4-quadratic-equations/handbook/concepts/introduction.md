# Introduction to Quadratic Equations

## Definition

A **quadratic equation** in the variable $x$ is an equation of the form

$$ax^2 + bx + c = 0$$

where $a$, $b$, and $c$ are real numbers and $a \neq 0$.

When we equate the quadratic polynomial $ax^2 + bx + c$ to zero, we get a quadratic equation.

## Standard Form

When we write the terms of the polynomial in descending order of their degrees, we get the **standard form**:

$$ax^2 + bx + c = 0, \quad a \neq 0$$

## Why must $a \neq 0$?

If $a = 0$, the equation becomes $bx + c = 0$, which is a linear equation, not quadratic. The $x^2$ term is what makes the equation degree two.

## Example from the Textbook: Prayer Hall

A charity trust wants to build a prayer hall with carpet area 300 m². The length is one metre more than twice the breadth.

Let breadth = $x$ metres.
Then length = $(2x + 1)$ metres.

Area = $(2x + 1) \cdot x = 2x^2 + x$

Given area = 300 m²:

$$2x^2 + x = 300$$
$$2x^2 + x - 300 = 0$$

This is a quadratic equation.

## Checking Whether an Equation is Quadratic

**Example 2 from NCERT:** Check whether the following are quadratic equations.

**(i)** $(x - 2)^2 + 1 = 2x - 3$

LHS = $(x - 2)^2 + 1 = x^2 - 4x + 4 + 1 = x^2 - 4x + 5$

So, $x^2 - 4x + 5 = 2x - 3$

$$x^2 - 6x + 8 = 0$$

This is quadratic.

**(ii)** $x(x + 1) + 8 = (x + 2)(x - 2)$

LHS = $x^2 + x + 8$
RHS = $x^2 - 4$

So, $x^2 + x + 8 = x^2 - 4$

$$x + 12 = 0$$

This is **not** quadratic (degree 1).

**(iii)** $x(2x + 3) = x^2 + 1$

LHS = $2x^2 + 3x$

So, $2x^2 + 3x = x^2 + 1$

$$x^2 + 3x - 1 = 0$$

This is quadratic.

**(iv)** $(x + 2)^3 = x^3 - 4$

LHS = $x^3 + 6x^2 + 12x + 8$

So, $x^3 + 6x^2 + 12x + 8 = x^3 - 4$

$$6x^2 + 12x + 12 = 0$$
$$x^2 + 2x + 2 = 0$$

This is quadratic (the $x^3$ terms cancel).

## Important Remark

Be careful! Sometimes an equation may appear to be quadratic but is not, and sometimes an equation may appear to be of higher degree but simplifies to a quadratic equation. Always simplify first.
