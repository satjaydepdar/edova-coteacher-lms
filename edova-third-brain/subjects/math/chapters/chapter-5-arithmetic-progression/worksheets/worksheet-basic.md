## Section A: Identifying APs (Based on NCERT Section 5.1–5.2)

**Q1.** Which of the following are arithmetic progressions? State the common difference for those that are.

(i) $2, 4, 8, 16, \ldots$

(ii) $10, 7, 4, 1, \ldots$

(iii) $1, 3, 6, 10, \ldots$

(iv) $-5, -1, 3, 7, \ldots$

**Q5.** Find the sum of the first 10 multiples of 5.

**Q1.**
(i) No — ratio is constant (2), not the difference.
(ii) Yes — $d = -3$.
(iii) No — differences are $2, 3, 4, \ldots$, not constant.
(iv) Yes — $d = 4$.

**Q2.** $29, 35$.

**Q3.** $a = 2$, $d = 5$. $a_{10} = 2 + 9(5) = 47$.

**Q4.** $a_4 = a + 3d = 20 \Rightarrow 5 + 3d = 20 \Rightarrow d = 5$.

**Q5.** $a = 5$, $d = 5$, $n = 10$. $S_{10} = \frac{10}{2}[10 + 9(5)] = 275$.
