## Section D: Case Study (5 × 2 = 10)

### Case Study 1: Auditorium Seating

A theatre has 20 seats in the first row, 22 seats in the second row, 24 seats in the third row, and so on, each row having 2 more seats than the previous one.

**Q16.** How many seats are there in the 15th row?

**Q17.** How many total seats are there in the first 15 rows?

### Case Study 2: Stacking Logs

200 logs are stacked so that the bottom row has 20 logs, the next row has 19 logs, the row above that has 18 logs, and so on, decreasing by 1 log per row, until the stack is used up.

**Q18.** In how many rows are the 200 logs placed?

**Q19.** How many logs are in the top row?

**A6.** $a = 3$, $d = 4$. $a_{20} = 3 + 19(4) = 79$.

**A7.** $a_4 = a + 3d = 20 \Rightarrow 5 + 3d = 20 \Rightarrow d = 5$.

**A8.** Two-digit multiples of 3: $12, 15, \ldots, 99$. $a = 12$, $d = 3$, $l = 99$. $12 + (n-1)3 = 99 \Rightarrow n = 30$.

**A9.** $a = -6$, $d = 5$. $S_{12} = \frac{12}{2}[2(-6) + 11(5)] = 6(43) = 258$.

**A10.** $a_1 = S_1 = 3(1)^2 + 5(1) = 8$. $S_2 = 3(4) + 10 = 22$, so $a_2 = S_2 - S_1 = 14$. First term $a = 8$, common difference $d = a_2 - a_1 = 6$.

**A11.** $a = 8$, $d = -5$. $S_{22} = \frac{22}{2}[16 + 21(-5)] = 11(-89) = -979$.

**A12.** $3 + (n-1)5 = 78 \Rightarrow n = 16$. $S_{16} = \frac{16}{2}[6 + 15(5)] = 8(81) = 648$.

**A13.** $a + 2d = 16$. $(a + 6d) - (a + 4d) = 12 \Rightarrow 2d = 12 \Rightarrow d = 6$. Then $a + 12 = 16 \Rightarrow a = 4$. AP: $4, 10, 16, 22, 28, \ldots$

**A14.** Multiples of 6 up to the 40th: $a = 6$, $d = 6$, $n = 40$. $S_{40} = \frac{40}{2}[12 + 39(6)] = 20(246) = 4920$.

**A15.** $a = 9$, $d = 8$. $\frac{n}{2}[18 + (n-1)8] = 636 \Rightarrow 4n^2 + 5n - 636 = 0$. Solving, $n = 12$.

**A16.** $a = 20$, $d = 2$. $a_{15} = 20 + 14(2) = 48$ seats.

**A17.** $S_{15} = \frac{15}{2}[40 + 14(2)] = \frac{15}{2}(68) = 510$ seats.

**A18.** $a = 20$, $d = -1$, $S_n = 200$. $n[41 - n] = 400 \Rightarrow n^2 - 41n + 400 = 0 \Rightarrow n = 16$ or $n = 25$. Since the number of logs per row cannot go negative, $n = 25$ is rejected. So the logs are placed in **16 rows**.

**A19.** Top row (16th row): $a_{16} = 20 - 15(1) = 5$ logs.
