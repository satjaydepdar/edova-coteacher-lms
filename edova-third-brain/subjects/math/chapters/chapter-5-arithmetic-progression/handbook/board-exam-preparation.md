# Board Exam Preparation: Arithmetic Progressions

## Expected Question Types

| Marks | Typical Question |
|---|---|
| 1 mark | Identify an AP; write the first term or common difference; recall a formula. |
| 2 marks | Find a specific term or common difference; check whether a number is a term. |
| 3 marks | Find the number of terms; solve a word problem using the $n$th term formula. |
| 4 marks | Find the sum of first $n$ terms; solve a real-life problem using $S_n$. |
| 5 marks (case study) | Multi-part real-life context involving both $a_n$ and $S_n$ (e.g., penalties, savings, production). |

## Frequent NCERT Topics

1. Identifying APs and finding the common difference (Exercise 5.1).
2. Finding the $n$th term when $a$, $d$, and $n$ are given (Exercise 5.2).
3. Finding the number of terms when $a$, $d$, and last term are given (Exercise 5.2).
4. Finding terms from the end of an AP (Exercise 5.2 Q17).
5. Sum of first $n$ terms using both formulas (Exercise 5.3).
6. Word problems on salaries, penalties, savings, prizes, and arrangements (Exercises 5.2 and 5.3).
7. Sum of positive integers divisible by a given number (Exercise 5.3 Q12, Q13, Q14).
8. Checking whether a number is a term of an AP (Example 6).

## Time Management

- 1-mark questions: ~1 minute each.
- 2-mark questions: ~2–3 minutes each.
- 3-mark questions: ~4–5 minutes each.
- 4-mark questions: ~6–7 minutes each.
- Case study questions: ~8–10 minutes each.

## Common Errors to Avoid

- Using $n$ instead of $(n - 1)$ in the $n$th term formula.
- Forgetting that $d$ can be negative or zero.
- Confusing the term number with the value of the term.
- Using the wrong sum formula when the last term is not known.
- Making sign errors when substituting negative values of $d$.
- Forgetting to verify that $n$ is a positive integer when checking if a number is a term.

## Sample Board-Style Questions

1. Find the 20th term of the AP $5, 8, 11, 14, \ldots$
2. Which term of the AP $3, 8, 13, 18, \ldots$ is 78?
3. How many two-digit numbers are divisible by 7?
4. Find the sum of the first 40 positive integers divisible by 6.
5. The 17th term of an AP exceeds its 10th term by 7. Find the common difference.
6. A sum of ₹700 is to be used to give seven cash prizes, each ₹20 less than the preceding one. Find the value of each prize.
7. The sum of the 4th and 8th terms of an AP is 24, and the sum of the 6th and 10th terms is 44. Find the first three terms.
