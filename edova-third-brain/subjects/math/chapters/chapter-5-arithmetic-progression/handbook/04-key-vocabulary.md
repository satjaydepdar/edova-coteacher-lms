## Key Terms

| Term | Definition |
|---|---|
| **Sequence** | An ordered list of numbers arranged according to a rule. |
| **Term** | Each number in a sequence. |
| **Arithmetic Progression (AP)** | A list of numbers in which each term is obtained by adding a fixed number to the preceding term, except the first term. |
| **First Term ($a$)** | The first number of an AP. |
| **Common Difference ($d$)** | The fixed number added to any term to get the next term; $d = a_{k+1} - a_k$. |
| **Finite AP** | An AP that has a finite number of terms and a last term. |
| **Infinite AP** | An AP that continues indefinitely and has no last term. |
| **General Form of an AP** | $a, a + d, a + 2d, a + 3d, \ldots$ |
| **$n$th Term ($a_n$)** | The term in the $n$th position; $a_n = a + (n - 1)d$. |
| **Last Term ($l$)** | The final term of a finite AP; $l = a + (n - 1)d$. |
| **Sum of First $n$ Terms ($S_n$)** | The total of the first $n$ terms; $S_n = \dfrac{n}{2}[2a + (n - 1)d] = \dfrac{n}{2}(a + l)$. |
| **Arithmetic Mean** | If $a, b, c$ are in AP, then $b$ is the arithmetic mean of $a$ and $c$, and $b = \dfrac{a + c}{2}$. |
