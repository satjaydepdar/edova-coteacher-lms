# Arithmetic Progressions

## Definition

An **arithmetic progression (AP)** is a list of numbers in which each term is obtained by adding a fixed number to the preceding term, except the first term.

The fixed number that is added is called the **common difference** and is denoted by $d$.

## General Form

An AP with first term $a$ and common difference $d$ is written as:

$$a,\ a + d,\ a + 2d,\ a + 3d,\ \ldots$$

## Examples

| AP | First Term ($a$) | Common Difference ($d$) |
|---|---|---|
| $1, 2, 3, 4, \ldots$ | $1$ | $1$ |
| $100, 70, 40, 10, \ldots$ | $100$ | $-30$ |
| $-3, -2, -1, 0, \ldots$ | $-3$ | $1$ |
| $3, 3, 3, 3, \ldots$ | $3$ | $0$ |
| $-1.0, -1.5, -2.0, -2.5, \ldots$ | $-1.0$ | $-0.5$ |

## How to Identify an AP

For a list of numbers $a_1, a_2, a_3, \ldots$, check whether:

$$a_2 - a_1 = a_3 - a_2 = a_4 - a_3 = \ldots = d$$

If the difference is the same every time, the list is an AP.

## Finite and Infinite APs

- A **finite AP** has a limited number of terms and a last term.
- An **infinite AP** continues indefinitely and has no last term.

## Note

To know an AP completely, we need both the first term $a$ and the common difference $d$.
