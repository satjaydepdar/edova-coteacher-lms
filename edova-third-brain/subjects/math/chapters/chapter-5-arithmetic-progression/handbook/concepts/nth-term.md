# $n$th Term of an AP

## Derivation of the Formula

Consider an AP with first term $a$ and common difference $d$:

$$a,\ a + d,\ a + 2d,\ a + 3d,\ \ldots$$

Observing the pattern:

- First term: $a_1 = a = a + (1 - 1)d$
- Second term: $a_2 = a + d = a + (2 - 1)d$
- Third term: $a_3 = a + 2d = a + (3 - 1)d$
- Fourth term: $a_4 = a + 3d = a + (4 - 1)d$

Continuing this pattern, the **$n$th term** is:

$$a_n = a + (n - 1)d$$

This is also called the **general term** of the AP.

## Uses of the Formula

The formula $a_n = a + (n - 1)d$ can be used to find:

1. Any term when $a$, $d$, and $n$ are known.
2. The number of terms $n$ when $a$, $d$, and $a_n$ are known.
3. The common difference $d$ when $a$, $n$, and $a_n$ are known.
4. The first term $a$ when $d$, $n$, and $a_n$ are known.

## Checking Whether a Number is a Term

To check whether a given number $x$ is a term of an AP:

1. Set $a_n = x$.
2. Solve for $n$.
3. If $n$ is a positive integer, then $x$ is a term of the AP; otherwise, it is not.

## Terms from the End

The $r$th term from the end of a finite AP with $n$ terms is the $(n - r + 1)$th term from the beginning.

Alternatively, reverse the AP so that the first term becomes the last term $l$ and the common difference becomes $-d$.
