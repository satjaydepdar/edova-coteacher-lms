# Revision Notes: Arithmetic Progressions

## 1. Identifying an AP

- Check the difference between consecutive terms.
- If $a_{k+1} - a_k$ is constant for all $k$, the sequence is an AP.
- The constant difference is called the common difference $d$.

## 2. Important Quantities

| Symbol | Meaning |
|---|---|
| $a$ | First term |
| $d$ | Common difference |
| $n$ | Number of terms / term position |
| $a_n$ or $l$ | $n$th term / last term |
| $S_n$ | Sum of first $n$ terms |

## 3. Key Formulas

- $n$th term: $a_n = a + (n - 1)d$
- Sum: $S_n = \dfrac{n}{2}[2a + (n - 1)d]$
- Sum using last term: $S_n = \dfrac{n}{2}(a + l)$

## 4. Common Problem Types

| Given | Required | Formula |
|---|---|---|
| $a, d, n$ | $a_n$ | $a_n = a + (n - 1)d$ |
| $a, d, a_n$ | $n$ | Solve $a_n = a + (n - 1)d$ |
| $a, n, S_n$ | $d$ | Use sum formula |
| $a, d, n$ | $S_n$ | $S_n = \dfrac{n}{2}[2a + (n - 1)d]$ |
| Two terms $a_m$ and $a_n$ | $a$ and $d$ | Form two linear equations |

## 5. Terms from the End

The $r$th term from the end of an AP with $n$ terms is the $(n - r + 1)$th term from the beginning.

Alternatively, reverse the AP: first term becomes $l$ and common difference becomes $-d$.

## 6. Important Tips for Board Exam

- Write the formula before substituting values.
- Check that $n$ is a positive integer when required.
- Be careful with negative values of $d$.
- For word problems, identify $a$ and $d$ first.
- Use $S_n = \dfrac{n}{2}(a + l)$ when the last term is known.
