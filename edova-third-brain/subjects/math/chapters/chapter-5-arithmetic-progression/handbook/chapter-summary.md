# Chapter Summary: Arithmetic Progressions

## Key Points

1. A **sequence** is an ordered list of numbers arranged according to a rule.
2. An **arithmetic progression (AP)** is a list of numbers in which each term is obtained by adding a fixed number to the preceding term, except the first term.
3. The fixed number added is called the **common difference** ($d$). It can be positive, negative, or zero.
4. The general form of an AP is:

   $$a,\ a + d,\ a + 2d,\ a + 3d,\ \ldots$$

5. A list of numbers $a_1, a_2, a_3, \ldots$ is an AP if $a_{k+1} - a_k$ is the same for all values of $k$.
6. The **$n$th term** (general term) of an AP with first term $a$ and common difference $d$ is:

   $$a_n = a + (n - 1)d$$

7. The **sum of the first $n$ terms** of an AP is:

   $$S_n = \frac{n}{2}[2a + (n - 1)d]$$

   or, when the last term $l$ is known:

   $$S_n = \frac{n}{2}(a + l)$$

8. The **arithmetic mean** of two numbers $a$ and $c$ is $b = \dfrac{a + c}{2}$, and $a, b, c$ are in AP.

## Common Mistakes to Avoid

- Using $n$ instead of $(n - 1)$ in the $n$th term formula.
- Forgetting that $d$ can be negative.
- Confusing the position of a term with its value.
- Applying the sum formula without identifying $a$, $d$, and $n$ correctly.
- Not checking that $n$ is a positive integer when determining if a number is a term.
