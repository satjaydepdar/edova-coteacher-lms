# Competency-Based Examples

## Example 1: Identify the AP

Which of the following are APs? If they form an AP, find the common difference and write three more terms.

(i) $0.2, 0.22, 0.222, 0.2222, \ldots$

(ii) $0, -4, -8, -12, \ldots$

(iii) $1^2, 3^2, 5^2, 7^2, \ldots$

**Solution:**

(i) $0.22 - 0.2 = 0.02$, $0.222 - 0.22 = 0.002$. Differences are not equal. **Not an AP.**

(ii) $-4 - 0 = -4$, $-8 - (-4) = -4$, $-12 - (-8) = -4$. Common difference $d = -4$. It is an AP. Next three terms: $-16, -20, -24$.

(iii) $1, 9, 25, 49, \ldots$ Differences: $8, 16, 24$. Not equal. **Not an AP.**

## Example 2: Error Analysis

A student calculates the 20th term of the AP $5, 8, 11, \ldots$ as $5 + 20 \times 3 = 65$. Is this correct? Explain.

**Solution:**

The calculation is incorrect. The correct formula is:

$$a_n = a + (n - 1)d$$

So,

$$a_{20} = 5 + (20 - 1) \times 3 = 5 + 57 = 62$$

The student used $n$ instead of $(n - 1)$.

## Example 3: Formulate a Problem

Create a real-life problem that can be modelled as an AP and solve it.

**Solution:**

**Problem:** Ramkali saved ₹5 in the first week of a year and then increased her weekly savings by ₹1.75. If in the $n$th week her weekly savings become ₹20.75, find $n$.

Here, $a = 5$, $d = 1.75$, $a_n = 20.75$.

$$20.75 = 5 + (n - 1)(1.75)$$

$$15.75 = (n - 1)(1.75)$$

$$n - 1 = 9 \Rightarrow n = 10$$

So, in the **10th week**, her savings become ₹20.75.

## Example 4: Justify the Step

In finding the sum of an AP, a student uses $S_n = \dfrac{n}{2}(a + l)$ even though the last term is not given. Is this the best choice? Why?

**Solution:**

It is not the best choice when the last term is unknown. The formula $S_n = \dfrac{n}{2}[2a + (n - 1)d]$ should be used because it uses $a$, $d$, and $n$, all of which are usually known or can be found.
