# Easy Worked Examples

## Example 1: Find the First Term and Common Difference

For the AP $\dfrac{3}{2}, \dfrac{1}{2}, -\dfrac{1}{2}, -\dfrac{3}{2}, \ldots$, write the first term $a$ and the common difference $d$.

**Solution:**

$$a = \frac{3}{2}$$

$$d = \frac{1}{2} - \frac{3}{2} = -1$$

So, $a = \dfrac{3}{2}$ and $d = -1$.

## Example 2: Identify an AP

Which of the following list of numbers form an AP? If they form an AP, write the next two terms:

(i) $4, 10, 16, 22, \ldots$

(ii) $1, -1, -3, -5, \ldots$

(iii) $-2, 2, -2, 2, -2, \ldots$

**Solution:**

(i) $10 - 4 = 6$, $16 - 10 = 6$, $22 - 16 = 6$. Common difference is $6$. It is an AP. Next two terms: $28, 34$.

(ii) $-1 - 1 = -2$, $-3 - (-1) = -2$, $-5 - (-3) = -2$. Common difference is $-2$. It is an AP. Next two terms: $-7, -9$.

(iii) $2 - (-2) = 4$, $-2 - 2 = -4$. Differences are not equal. It is **not** an AP.

## Example 3: Find the 10th Term

Find the 10th term of the AP $2, 7, 12, \ldots$

**Solution:**

Here, $a = 2$, $d = 7 - 2 = 5$, and $n = 10$.

$$a_{10} = a + (10 - 1)d = 2 + 9 \times 5 = 2 + 45 = 47$$

The 10th term is $47$.
