# ICT Integration

## Recommended Tools

1. **GeoGebra / Desmos**
   - Plot pairs of linear equations dynamically.
   - Drag sliders to show how changing coefficients affects the lines.

2. **Microsoft Excel / Google Sheets**
   - Create tables of values for linear equations.
   - Plot lines and observe intersections.

3. **Kahoot / Quizizz / Google Forms**
   - Quick quizzes on consistency tests and method selection.
   - True/false questions on graphical interpretations.

## Suggested Activities

- **Graph Explorer:** Students input equations in GeoGebra and classify the solution type.
- **Method Matcher:** Drag equation pairs to the most efficient solution method box.
- **Case Study Simulator:** Use a spreadsheet to model taxi fares or shopping bills.
- **Verification Challenge:** Use an online solver to check answers and identify errors.
