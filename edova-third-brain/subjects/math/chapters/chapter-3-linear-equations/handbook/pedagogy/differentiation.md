# Differentiation Strategies

## For Struggling Learners

- Provide pre-structured templates for forming equations from word problems.
- Start with simple integer coefficients before introducing fractions.
- Use graph paper and labelled axes for graphical solutions.
- Allow use of a formula card for cross-multiplication.

## For Average Learners

- Mixed practice on all three algebraic methods.
- Scaffolded problems with partially completed steps.
- Pair work on NCERT Exercises 3.2, 3.3, and 3.4.

## For Advanced Learners

- Prove the cross-multiplication formula using elimination.
- Explore pairs with parameters (finding $k$ for consistency).
- Create original word problems and case studies.

## Visual Learners

- Use coloured lines on graph paper for graphical solutions.
- Highlight coefficients and signs in different colours.

## Kinesthetic Learners

- Use string or rulers on a large coordinate grid.
- Role-play real-life situations before forming equations.

## Verbal Learners

- Explain each step aloud to a partner.
- Write "how-to" guides for each solution method.
