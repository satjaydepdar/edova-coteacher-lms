# Board Exam Preparation: Pair of Linear Equations in Two Variables

## Expected Question Types

| Marks | Typical Question |
|---|---|
| 1 mark | State whether a pair is consistent/inconsistent/dependent; recall general form. |
| 2 marks | Solve a simple pair by substitution or elimination; check consistency using ratios. |
| 3 marks | Solve a word problem by forming and solving a pair of equations. |
| 4 marks | Solve by cross-multiplication or reduce a non-linear pair to linear form. |
| 5 marks (case study) | Real-life application involving two unknown quantities (taxi charges, ages, digits, etc.). |

## Frequent NCERT Topics

1. Forming equations from word problems (Exercise 3.1, 3.2, 3.3, 3.4).
2. Checking consistency by comparing coefficient ratios (Exercise 3.2).
3. Solving by substitution method (Exercise 3.3).
4. Solving by elimination method (Exercise 3.3).
5. Solving by cross-multiplication method (Exercise 3.4).
6. Equations reducible to linear form (Exercise 3.5).
7. Mixed word problems on ages, digits, speeds, coins, and fixed charges.

## Time Management

- 1-mark questions: ~1 minute each.
- 2-mark questions: ~3 minutes each.
- 3-mark questions: ~5 minutes each.
- 4-mark questions: ~7 minutes each.
- Case study questions: ~8–10 minutes each.

## Common Errors to Avoid

- Sign errors while transposing terms.
- Incorrect substitution after finding the value of one variable.
- Forgetting to verify the solution in both original equations.
- Misidentifying the nature of lines from coefficient ratios.
- Applying cross-multiplication formula without writing it correctly.
- Not converting non-linear equations to linear form before solving.

## Sample Board-Style Questions

1. Solve the following pair of equations by substitution: $x + y = 14$, $x - y = 4$.
2. Solve by elimination: $3x + 4y = 10$ and $2x - 2y = 2$.
3. Find the value of $k$ for which the pair $2x + 3y = 7$ and $(k - 1)x + (k + 2)y = 3k$ has infinitely many solutions.
4. A fraction becomes $\dfrac{9}{11}$ if 2 is added to both numerator and denominator. If 3 is added to both, it becomes $\dfrac{5}{6}$. Find the fraction.
5. The sum of the digits of a two-digit number is 9. Nine times this number is twice the number obtained by reversing the digits. Find the number.
