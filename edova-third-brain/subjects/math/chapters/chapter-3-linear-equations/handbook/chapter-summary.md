# Chapter Summary: Pair of Linear Equations in Two Variables

## Key Points

1. A pair of linear equations in two variables can be written as:
   $$a_1x + b_1y + c_1 = 0$$
   $$a_2x + b_2y + c_2 = 0$$

2. **Graphical Method:** The graph of a pair of linear equations is represented by two lines.
   - If the lines intersect at a point, the pair has a **unique solution** (consistent).
   - If the lines are parallel, the pair has **no solution** (inconsistent).
   - If the lines coincide, the pair has **infinitely many solutions** (dependent/consistent).

3. **Algebraic Condition for Consistency:**
   - If $\dfrac{a_1}{a_2} \neq \dfrac{b_1}{b_2}$, the pair is **consistent** with a unique solution.
   - If $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}$, the pair is **inconsistent**.
   - If $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$, the pair is **dependent** with infinitely many solutions.

4. **Algebraic Methods:**
   - **Substitution Method:** Express one variable in terms of the other and substitute.
   - **Elimination Method:** Make coefficients of one variable equal and eliminate it.
   - **Cross-Multiplication Method:** Use the formula
     $$\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}.$$

5. **Equations Reducible to Linear Form:** Some equations that are not linear can be reduced to linear form by suitable substitutions.

## Common Mistakes to Avoid

- Forgetting that $a$ and $b$ cannot both be zero in a linear equation in two variables.
- Confusing the condition for parallel lines with the condition for coincident lines.
- Arithmetic errors while multiplying equations in the elimination method.
- Not substituting the final values back into both original equations to verify.
