# Cross-Multiplication Method

## Formula

For the pair:

$$a_1x + b_1y + c_1 = 0$$
$$a_2x + b_2y + c_2 = 0$$

the solution is given by:

$$\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}$$

provided $a_1b_2 - a_2b_1 \neq 0$.

## When to Use

The cross-multiplication method is useful when coefficients are fractions or large numbers, and when the other methods seem lengthy.

## Example

Solve:

$$2x + 3y = 8 \quad \Rightarrow \quad 2x + 3y - 8 = 0$$
$$3x - 4y = 5 \quad \Rightarrow \quad 3x - 4y - 5 = 0$$

Here, $a_1 = 2$, $b_1 = 3$, $c_1 = -8$, $a_2 = 3$, $b_2 = -4$, $c_2 = -5$.

Using the formula:

$$\frac{x}{(3)(-5) - (-4)(-8)} = \frac{y}{(-8)(3) - (-5)(2)} = \frac{1}{(2)(-4) - (3)(3)}$$

$$\frac{x}{-15 - 32} = \frac{y}{-24 + 10} = \frac{1}{-8 - 9}$$

$$\frac{x}{-47} = \frac{y}{-14} = \frac{1}{-17}$$

Therefore:

$$x = \frac{-47}{-17} = \frac{47}{17}, \quad y = \frac{-14}{-17} = \frac{14}{17}$$

## Derivation Hint

The formula is obtained by applying the elimination method in a general form. It is worth memorising for quick calculations.
