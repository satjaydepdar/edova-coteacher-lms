# Elimination Method

## Steps

1. Multiply one or both equations by suitable numbers so that the coefficients of one variable become equal.
2. Add or subtract the equations to eliminate that variable.
3. Solve the resulting equation in one variable.
4. Substitute this value back into one of the original equations to find the other variable.

## When to Use

The elimination method is convenient when the coefficients can be made equal by simple multiplication.

## Example

Solve:

$$9x - 4y = 2000 \quad \text{...(1)}$$
$$7x - 3y = 2000 \quad \text{...(2)}$$

Multiply equation (1) by 3 and equation (2) by 4:

$$27x - 12y = 6000 \quad \text{...(3)}$$
$$28x - 12y = 8000 \quad \text{...(4)}$$

Subtract equation (3) from equation (4):

$$x = 2000$$

Substitute in equation (1):

$$9(2000) - 4y = 2000$$
$$18000 - 4y = 2000$$
$$4y = 16000$$
$$y = 4000$$

So the solution is $x = 2000$, $y = 4000$.

## Special Cases

- If elimination leads to $0 = 0$, the pair has infinitely many solutions.
- If elimination leads to a false statement like $0 = 9$, the pair has no solution.

## Master Check

- [ ] I can make coefficients equal by multiplication.
- [ ] I know when to add and when to subtract the equations.
- [ ] I can identify special cases from the elimination result.
