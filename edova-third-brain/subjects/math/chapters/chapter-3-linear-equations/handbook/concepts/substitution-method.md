# Substitution Method

## Steps

1. From one of the equations, express one variable in terms of the other.
2. Substitute this expression into the second equation.
3. Solve the resulting equation in one variable.
4. Substitute the value obtained back into the expression from Step 1 to find the other variable.

## When to Use

The substitution method is convenient when it is easy to isolate one of the variables.

## Example

Solve:

$$7x - 15y = 2 \quad \text{...(1)}$$
$$x + 2y = 3 \quad \text{...(2)}$$

From equation (2): $x = 3 - 2y$.

Substitute in equation (1):

$$7(3 - 2y) - 15y = 2$$
$$21 - 14y - 15y = 2$$
$$-29y = -19$$
$$y = \frac{19}{29}$$

Substitute back:

$$x = 3 - 2\left(\frac{19}{29}\right) = \frac{87 - 38}{29} = \frac{49}{29}$$

So the solution is $x = \dfrac{49}{29}$, $y = \dfrac{19}{29}$.

## Special Cases

- If substitution leads to a true statement with no variable (e.g., $5 = 5$), the pair has infinitely many solutions.
- If substitution leads to a false statement (e.g., $0 = 9$), the pair has no solution.

## Master Check

- [ ] I can express one variable in terms of the other.
- [ ] I can substitute correctly without sign errors.
- [ ] I can identify dependent and inconsistent pairs from the result.
