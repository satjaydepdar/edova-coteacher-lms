# Competency-Based Examples

## Example 1: Choose the Method

Solve $3x + 4y = 10$ and $2x - 2y = 2$. Which method is most efficient?

**Solution:**

The second equation can be simplified to $x - y = 1$, giving $x = y + 1$. Substitution is efficient.

Substitute in the first equation:

$$3(y + 1) + 4y = 10$$
$$7y + 3 = 10$$
$$7y = 7$$
$$y = 1$$

Then $x = 1 + 1 = 2$.

The solution is $x = 2$, $y = 1$.

## Example 2: Error Analysis

A student solves $2x + 3y = 8$ and $4x + 6y = 7$ and gets $0 = 9$. What does this mean?

**Solution:**

The result $0 = 9$ is a false statement. This means the pair of equations has no solution. The lines are parallel and the pair is inconsistent.

## Example 3: Formulate a Problem

Create a real-life problem that can be solved using a pair of linear equations.

**Solution:**

Sample problem:

"The cost of 5 pencils and 7 pens is ₹50. The cost of 7 pencils and 5 pens is ₹46. Find the cost of one pencil and one pen."

Let cost of one pencil = ₹$x$ and one pen = ₹$y$.

$$5x + 7y = 50$$
$$7x + 5y = 46$$

## Example 4: Justify the Step

A student writes: "Since $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2}$, the lines are parallel." Is this always true?

**Solution:**

No. If $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} = \dfrac{c_1}{c_2}$, the lines are coincident, not parallel. The lines are parallel only when $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2} \neq \dfrac{c_1}{c_2}$.
