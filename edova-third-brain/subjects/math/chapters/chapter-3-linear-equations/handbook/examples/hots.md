# Higher Order Thinking Skills (HOTS) Examples

## Example 7: Two-Digit Number Problem

The sum of a two-digit number and the number obtained by reversing its digits is 66. If the digits differ by 2, find the number. How many such numbers are there?

**Solution:**

Let the ten's digit be $x$ and the unit's digit be $y$.

The original number is $10x + y$.
The reversed number is $10y + x$.

Given:

$$(10x + y) + (10y + x) = 66$$
$$11x + 11y = 66$$
$$x + y = 6 \quad \text{...(1)}$$

Also, the digits differ by 2:

$$x - y = 2 \quad \text{...(2)} \quad \text{or} \quad y - x = 2 \quad \text{...(3)}$$

**Case 1:** Solving (1) and (2):

Adding: $2x = 8 \Rightarrow x = 4$, so $y = 2$. Number = 42.

**Case 2:** Solving (1) and (3):

Adding: $2y = 8 \Rightarrow y = 4$, so $x = 2$. Number = 24.

There are two such numbers: 42 and 24.

## Example 8: Value of $k$ for Infinitely Many Solutions

Find the value of $k$ for which the pair has infinitely many solutions:

$$2x + 3y = 7$$
$$(k - 1)x + (k + 2)y = 3k$$

**Solution:**

Rewrite in general form:

$$2x + 3y - 7 = 0$$
$$(k - 1)x + (k + 2)y - 3k = 0$$

For infinitely many solutions:

$$\frac{2}{k-1} = \frac{3}{k+2} = \frac{-7}{-3k}$$

From the first two ratios:

$$2(k + 2) = 3(k - 1)$$
$$2k + 4 = 3k - 3$$
$$k = 7$$

Verify with the third ratio:

$$\frac{3}{7+2} = \frac{1}{3}, \quad \frac{7}{3(7)} = \frac{1}{3}$$

Thus, $k = 7$.

## Example 9: Fixed and Variable Charges

A lending library has a fixed charge for the first three days and an additional charge for each day thereafter. Saritha paid ₹27 for a book kept for seven days, while Susy paid ₹21 for a book kept for five days. Find the fixed charge and the charge for each extra day.

**Solution:**

Let fixed charge = ₹$x$ and extra charge per day = ₹$y$.

Saritha kept the book for 7 days, so extra days = 4:

$$x + 4y = 27 \quad \text{...(1)}$$

Susy kept the book for 5 days, so extra days = 2:

$$x + 2y = 21 \quad \text{...(2)}$$

Subtract equation (2) from equation (1):

$$2y = 6$$
$$y = 3$$

Substitute in equation (2):

$$x + 2(3) = 21$$
$$x = 15$$

Fixed charge = ₹15, extra charge per day = ₹3.
