# Board Level Worked Examples

## Example 1: Solve by Substitution

Solve the following pair by substitution method:

$$s - t = 3$$
$$\frac{s}{3} + \frac{t}{2} = 6$$

**Solution:**

From the first equation: $s = t + 3$.

Substitute in the second equation:

$$\frac{t + 3}{3} + \frac{t}{2} = 6$$

Multiply by 6:

$$2(t + 3) + 3t = 36$$
$$2t + 6 + 3t = 36$$
$$5t = 30$$
$$t = 6$$

Therefore $s = 6 + 3 = 9$.

Solution: $s = 9$, $t = 6$.

## Example 2: Solve by Elimination

Solve:

$$3x + 4y = 10$$
$$2x - 2y = 2$$

**Solution:**

Multiply the second equation by 2:

$$4x - 4y = 4 \quad \text{...(3)}$$

Add equations (1) and (3):

$$7x = 14$$
$$x = 2$$

Substitute in equation (1):

$$3(2) + 4y = 10$$
$$4y = 4$$
$$y = 1$$

Solution: $x = 2$, $y = 1$.

## Example 3: Consistency Check

Find whether the following pair is consistent or inconsistent:

$$5x - 3y = 11$$
$$-10x + 6y = -22$$

**Solution:**

$$\frac{a_1}{a_2} = \frac{5}{-10} = -\frac{1}{2}$$
$$\frac{b_1}{b_2} = \frac{-3}{6} = -\frac{1}{2}$$
$$\frac{c_1}{c_2} = \frac{-11}{22} = -\frac{1}{2}$$

Since all three ratios are equal, the pair is dependent (consistent) with infinitely many solutions.

## Example 4: Fraction Problem

A fraction becomes $\dfrac{9}{11}$ if 2 is added to both numerator and denominator. If 3 is added to both, it becomes $\dfrac{5}{6}$. Find the fraction.

**Solution:**

Let the fraction be $\dfrac{x}{y}$.

Given:

$$\frac{x + 2}{y + 2} = \frac{9}{11}$$
$$11(x + 2) = 9(y + 2)$$
$$11x - 9y = -4 \quad \text{...(1)}$$

Also:

$$\frac{x + 3}{y + 3} = \frac{5}{6}$$
$$6(x + 3) = 5(y + 3)$$
$$6x - 5y = -3 \quad \text{...(2)}$$

Multiply equation (1) by 5 and equation (2) by 9:

$$55x - 45y = -20 \quad \text{...(3)}$$
$$54x - 45y = -27 \quad \text{...(4)}$$

Subtract equation (4) from equation (3):

$$x = 7$$

Substitute in equation (2):

$$6(7) - 5y = -3$$
$$42 - 5y = -3$$
$$5y = 45$$
$$y = 9$$

The fraction is $\dfrac{7}{9}$.

## Example 5: Solve by Cross-Multiplication

Solve:

$$2x + 3y = 8$$
$$3x - 4y = 5$$

**Solution:**

Rewrite:

$$2x + 3y - 8 = 0$$
$$3x - 4y - 5 = 0$$

Using cross-multiplication:

$$\frac{x}{(3)(-5) - (-4)(-8)} = \frac{y}{(-8)(3) - (-5)(2)} = \frac{1}{(2)(-4) - (3)(3)}$$

$$\frac{x}{-15 - 32} = \frac{y}{-24 + 10} = \frac{1}{-8 - 9}$$

$$\frac{x}{-47} = \frac{y}{-14} = \frac{1}{-17}$$

Therefore:

$$x = \frac{47}{17}, \quad y = \frac{14}{17}$$
