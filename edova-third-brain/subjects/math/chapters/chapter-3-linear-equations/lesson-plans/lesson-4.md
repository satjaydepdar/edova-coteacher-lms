# Lesson 4

## Chapter 3: Pair of Linear Equations in Two Variables
### Topic: Cross-Multiplication Method and Equations Reducible to Linear Form (NCERT Sections 3.4 and 3.5)

**Duration:** 45 minutes
**Target Audience:** Class X Students

---

### 1. Learning Objectives

By the end of this lesson, students will be able to:
- State and apply the cross-multiplication formula.
- Reduce non-linear equations to a pair of linear equations using substitution.
- Choose the most efficient method for a given pair of equations.

---

### 2. Key Concepts

- Cross-multiplication formula:
  $$\frac{x}{b_1c_2 - b_2c_1} = \frac{y}{c_1a_2 - c_2a_1} = \frac{1}{a_1b_2 - a_2b_1}$$
- Reducible equations: substitute $u = \dfrac{1}{x}$ and $v = \dfrac{1}{y}$ to linearize equations of the form $\dfrac{a}{x} + \dfrac{b}{y} = c$.
- Convert back to original variables after solving.

---

### 3. Teaching-Learning Process

#### Introduction (10 mins)
- **Hook:** "Is there a formula that works for any pair of linear equations?"
- **Recall:** Cross-multiplication from ratio and proportion.
- **Derive:** Show how elimination leads to the cross-multiplication formula.

#### Main Activity (25 mins)
- **Cross-Multiplication Example:** Solve $2x + 3y = 8$ and $3x - 4y = 5$ using the formula.
- **Reducible Equations Example:** Solve $\dfrac{2}{x} + \dfrac{3}{y} = 13$ and $\dfrac{5}{x} - \dfrac{4}{y} = -2$.
- **Method Selection:** Discuss which method is best for different pairs.
- **Student Practice:** Begin NCERT Exercises 3.4 and 3.5 in class.

#### Conclusion (10 mins)
- Summarise all four solution methods.
- Provide a decision-making flowchart.
- Assign remaining Exercise 3.4 and 3.5 questions as homework.

---

### 4. Assessment

- **Exit Ticket:** Which method would you use to solve $7x - 15y = 2$ and $x + 2y = 3$? Justify your choice.
