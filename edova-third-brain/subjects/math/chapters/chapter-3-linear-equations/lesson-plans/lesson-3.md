# Lesson 3

## Chapter 3: Pair of Linear Equations in Two Variables
### Topic: Elimination Method (NCERT Section 3.3.2)

**Duration:** 45 minutes
**Target Audience:** Class X Students

---

### 1. Learning Objectives

By the end of this lesson, students will be able to:
- Make coefficients of one variable equal by multiplying equations.
- Eliminate one variable by adding or subtracting equations.
- Solve a pair of linear equations using the elimination method.

---

### 2. Key Concepts

- Elimination method steps:
  1. Multiply equations to make coefficients of one variable equal.
  2. Add or subtract to eliminate that variable.
  3. Solve for the remaining variable.
  4. Substitute back to find the other variable.
- Same arithmetic rules for special cases apply as in substitution.

---

### 3. Teaching-Learning Process

#### Introduction (10 mins)
- **Hook:** "What if neither variable is easy to isolate?"
- **Recall:** Adding and subtracting equations.
- **Explain:** The idea of elimination — removing one variable.

#### Main Activity (25 mins)
- **Example 8:** Income-expenditure problem solved by elimination.
- **Example 9:** Show inconsistency using elimination.
- **Example 10:** Two-digit number problem.
- **Student Practice:** Begin NCERT Exercise 3.3 in class.

#### Conclusion (10 mins)
- Compare substitution and elimination methods.
- Discuss when each method is more efficient.
- Assign remaining Exercise 3.3 questions as homework.

---

### 4. Assessment

- **Exit Ticket:** Solve $3x + 4y = 10$ and $2x - 2y = 2$ by elimination.
