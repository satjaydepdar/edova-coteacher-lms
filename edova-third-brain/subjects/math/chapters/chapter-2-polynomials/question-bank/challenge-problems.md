# Challenge Problems

**Q1.** If $\alpha$ and $\beta$ are the zeroes of $x^2 - px + q$, find the value of $\alpha^3 + \beta^3$ in terms of $p$ and $q$.

**Q2.** Find all the zeroes of $x^4 - 13x^2 + 36$.

**Q3.** If one zero of the polynomial $3x^2 - 8x + k$ is the reciprocal of the other, find $k$.

**Q4.** For what value of $k$ does the polynomial $x^2 - 4x + k$ have equal zeroes?

**Q5.** If $\alpha$, $\beta$, $\gamma$ are the zeroes of $x^3 - 6x^2 + 11x - 6$, find $\alpha^2 + \beta^2 + \gamma^2$.

---

## Answers

**A1.** $\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = p^3 - 3pq$.

**A2.** Let $y = x^2$. Then $y^2 - 13y + 36 = 0 \Rightarrow (y - 4)(y - 9) = 0$. So $x^2 = 4$ or $x^2 = 9$. Zeroes: $\pm 2$, $\pm 3$.

**A3.** Let zeroes be $\alpha$ and $\frac{1}{\alpha}$. Product $= 1 = \frac{k}{3}$, so $k = 3$.

**A4.** For equal zeroes, discriminant $= 0$. $16 - 4k = 0 \Rightarrow k = 4$.

**A5.** $\alpha + \beta + \gamma = 6$, $\alpha\beta + \beta\gamma + \gamma\alpha = 11$.

$\alpha^2 + \beta^2 + \gamma^2 = (\alpha + \beta + \gamma)^2 - 2(\alpha\beta + \beta\gamma + \gamma\alpha) = 36 - 22 = 14$.
