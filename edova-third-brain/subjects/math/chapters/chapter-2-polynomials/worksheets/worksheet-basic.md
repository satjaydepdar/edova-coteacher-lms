## Section A: Identify Polynomials (Based on NCERT Section 2.1)

**Q1.** Which of the following are polynomials in one variable? State reasons.

(i) $4x^3 - 2x + 1$

(ii) $\frac{1}{x} + 2$

(iii) $y^2 - 5y + 6$

(iv) $\sqrt{x} + 3$

(v) $x^{-2} + 5$

**Q2.** Write the degree of each polynomial:

(i) $7x^5 - 3x^2 + x - 8$

(ii) $2x^3 - 5x^2 + x - 1$

(iii) $9$

(iv) $x^2 - 5x + 6$

**Q3.** Find the zero of each polynomial:

(i) $3x - 9$

(iii) $2x - 7$

**Q4.** If $p(x) = x^2 - 3x - 4$, find:

(i) $p(0)$

## Section C: Classification

**Q5.** Classify each polynomial as linear, quadratic, or cubic:

(i) $3x - 9$

(ii) $x^2 - 5x + 6$

(iii) $2x^3 - 5x^2 + x - 1$

(iv) $7$

<summary><strong>Answer Key</strong></summary>

**Q1.**
(i) Yes — powers of $x$ are whole numbers.
(ii) No — $\frac{1}{x} = x^{-1}$ has negative power.
(iii) Yes — powers of $y$ are whole numbers.
(iv) No — $\sqrt{x} = x^{1/2}$ has fractional power.
(v) No — $x^{-2}$ has negative power.

**Q2.**
(i) $5$
(ii) $3$
(iii) $0$
(iv) $2$

**Q3.**
(i) $3$
(ii) $-2$
(iii) $\frac{7}{2}$

**Q4.**
(i) $p(0) = -4$
(ii) $p(-1) = 0$
(iii) $p(2) = -6$

**Q5.**
(i) Linear
(ii) Quadratic
(iii) Cubic
(iv) Constant (degree 0)
