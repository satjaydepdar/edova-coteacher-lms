## Prompt: Radial Infographic Mind Map Transformation
(More Professional/Modern)
Transform the provided visual content into a radial, infographic-style conceptual map centred around a single core idea.

### 1. Structure
Build the output as a balanced branching diagram:
Place the main concept at the centre using a clean circular focal element
Extend primary themes outward as clearly separated branches
Organise supporting points as tightly grouped sub-nodes within each branch

### 2. Layout & Composition
Ensure a clean, high-quality layout:
Distribute branches evenly to maintain visual symmetry
Maintain precise alignment and consistent spacing
Treat each branch as a distinct visual cluster
Limit the number of sub-nodes per branch to avoid clutter

### 3. Visual Design System
Apply a modern, professional infographic style:
Use a dark or neutral background with subtle gradients
Apply a restricted colour palette, assigning one colour per branch
Use soft highlights or glow accents to emphasise key nodes
Keep connectors thin, smooth, and consistent

### 4. Icons & Visual Cues
Assign each branch a simple, meaningful icon
Use minimal, clean iconography (flat or slightly dimensional)
Ensure all icons are consistent in style and scale

### 5. Node Formatting
For each node:
Use a two-part format:
Short label (2–4 words)
Concise supporting line (6–10 words max)
Apply clear visual hierarchy:
Labels → larger and bold
Supporting text → lighter and secondary
Ensure all text is highly legible and aligned

### 6. Overall Look & Feel
Prioritise a diagram-first, presentation-quality design
Keep the output clean, structured, and visually balanced
Avoid decorative or illustrative styles, focus on clarity and precision

### 7. Output Requirements
The final output should be:
16:9 aspect ratio
Suitable for slides, reports, or executive presentations
Comparable to a high-end dashboard or consulting infographic

### 8. Optional Refinement
Maintain consistent visual density across all branches
Ensure no section appears heavier or more crowded than others

## Prompt: Illustrated Storytelling Mind Map Transformation
Transform the attached mind map into a visually rich, illustrated mind map with a light, clean background.
The final output should follow a storytelling infographic style, similar to hand-crafted educational visuals, not a dark UI or dashboard.

### 1. Layout & Structure
Place the main concept clearly at the centre
Extend branches outward in an organic, flowing layout
Allow branches to curve naturally, like a hand-drawn diagram
Group related ideas into visually distinct clusters

### 2. Visual Style
Use a light background (white or soft neutral tones)
Apply soft, warm, slightly muted colours
Avoid:
dark themes
neon effects
heavy contrast
Keep the overall look bright, clean, and inviting

### 3. Illustrations (Critical Element)
Replace simple icons with small, detailed illustrations for each key concept
Use a consistent illustration style across the entire map
Ensure visuals feel:
educational
slightly playful
not corporate
Integrate illustrations directly into the nodes, not as separate elements

### 4. Typography & Content
Keep labels short and clear
Use a slightly informal, readable style
Maintain strong readability with clear spacing and hierarchy

### 5. Composition
Allow variation in node sizes to create visual interest
Avoid perfectly uniform shapes or boxes
Aim for a more organic, natural composition
Balance the layout so it feels fluid rather than grid-based

### 6. Output Requirements
16:9 aspect ratio
High resolution
Suitable for:
presentations
educational content

### 7. Critical Instruction
The final output must look like an illustrated educational infographic or visual story, not a technical diagram or UI dashboard.
Prioritise:
visual storytelling
warmth
clarity
over rigid structure or technical precision



## Prompt: Step-by-Step Learning Flowchart
Convert the NotebookLM content into a clear, step-by-step flowchart that explains the process of learning a new skill.

### 1. Overall Structure
Design the flow as a linear, directional sequence
Use either:
left → right, or
top → bottom
Ensure each step logically follows from the previous one

### 2. Flowchart Design
Break the process into clearly defined steps, each represented as a separate node
Use directional arrows to indicate progression between steps
Include decision points where necessary:
Show branching paths
Represent alternative outcomes clearly

### 3. Process Organisation
Group related steps into distinct phases if the process includes multiple stages
Ensure each phase is visually clear and easy to follow

### 4. Step Content
For each step:
Include a short, clear title
Add a brief one-line description explaining its role in the process

### 5. Layout & Clarity
Keep the layout clean, structured, and easy to read
Prioritise:
logical sequencing
visual clarity
simplicity
Avoid clutter and overly dense text

### 6. Output Requirements
16:9 aspect ratio
Presentation-ready format
Strong emphasis on a diagrammatic flow, not text-heavy blocks


## Prompt: Interactive Mind Map Dashboard
Transform the attached mind map into an interactive mind map dashboard with a clean, refined, and professional design.

### 1. Overall Style
Use a light background with generous white space
Follow a minimalist aesthetic
Apply soft, neutral colour tones
Maintain a calm, uncluttered visual feel

### 2. Design System
Avoid illustrations
Use simple geometric shapes and subtle icons
Apply thin, precise connectors
Ensure clean alignment and visual consistency

### 3. Layout
Keep a central concept with clearly spaced branches
Use grid-based alignment for balance and precision
Maintain consistent spacing and proportions across all elements

### 4. Typography
Use clean, modern typography
Apply a strong visual hierarchy:
headings → clear and prominent
labels → concise and readable
Ensure all text is highly legible

### 5. Output Requirements
16:9 aspect ratio
Fully presentation-ready
Comparable to a high-end consulting or product design slide

### 6. Critical Instruction
Prioritise:
clarity
simplicity
elegance
The final output should feel:
premium
minimal
professionally designed
